# Flight Booking System — Full Stack

This project implements the XTechon Flight Booking System assignment (search, dynamic pricing, wallet, ticket PDF, booking history). See assignment: `XTechon_Flight_Assignment_Dec2025.pdf`. :contentReference[oaicite:1]{index=1}

## Tech stack
- Backend: Node.js + Express + Mongoose
- Database: MongoDB
- Frontend: React (Vite) + TailwindCSS
- PDF: pdfkit
- Container: Docker & Docker Compose

## Quick start (local)
1. Clone repo
2. Start with Docker Compose (recommended):
   ```bash
   docker-compose up --build
