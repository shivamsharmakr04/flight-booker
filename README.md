# Flight Booker

A full-stack flight reservation application built with React, Node.js, Express, Tailwind CSS, and JWT authentication. It demonstrates a complete booking workflow from flight search to seat selection, checkout, booking history, and PDF ticket generation.

## ✨ Highlights

- ✈️ Flight search and filtering
- 💺 Interactive seat selection
- 👥 Passenger management
- 💳 Payment-flow simulation
- 💰 Wallet and balance workflow
- 🔐 JWT authentication
- 🎟️ Booking history and digital boarding passes
- 📄 Server-side PDF ticket generation
- 📱 Responsive UI with Tailwind CSS

## 🧰 Tech Stack

**Frontend:** React, Vite, React Router, Tailwind CSS, Framer Motion, Axios  
**Backend:** Node.js, Express.js  
**Authentication:** JWT  
**Database:** MongoDB / application data store  
**PDF:** PDFKit

## 🏗️ Booking Flow

```text
Search
  ↓
Select Flight
  ↓
Choose Seats
  ↓
Passenger Details
  ↓
Checkout
  ↓
Confirm Booking
  ↓
Generate E-Ticket
```

## 🚀 Getting Started

```bash
git clone https://github.com/shivamsharmakr04/flight-booker.git
cd flight-booker
```

Install dependencies for the frontend and backend:

```bash
npm install
cd backend
npm install
```

Start the backend and frontend development servers according to the project scripts.
